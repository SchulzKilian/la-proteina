## CAVEATS / GOTCHAS (memory-tagged)

1. **PYTHON_EXEC must be exported** ([[feedback_export_python_exec]]). The submit script does this. If you ever run the driver directly from a bare shell (skipping SLURM), `export PYTHON_EXEC=/home/ks2218/conda_envs/laproteina_env/bin/python` first.

2. **Stale tmp_dirs from a crashed eval** ([[feedback_eval_tmp_dir_sweep]]): `evaluate.py` asserts `tmp_dir` does not exist. The driver `clean_cell_state` does `rm -rf` before each cell. If a cell crashed mid-eval AND its entry made it into `cells.json` anyway, the cell won't be re-run automatically — delete the entry from `cells.json` to retry.

3. **nsteps=400 is non-negotiable** (CLAUDE.md hard rule). Inherited from `configs/inference_base.yaml`. Do NOT override down even for "smoke" runs.

4. **seed=5** is paired-by-noise across all cells. Same noise → cell-to-cell deltas come from architecture (mask + K), not init.

5. **gpu-q-43 is broken** — the submit script excludes it.

6. **The diagnostic is an UPPER bound on layer-hybrid viability.** Dense-trained upper layers were never exposed to sparsified intermediate representations; if they fail under partial sparsification at inference, a properly trained hybrid might still work. If they pass, a hybrid might still fail to train — non-catastrophic ≠ sufficient. State this explicitly in any write-up.

7. **cells.json is cumulative.** To re-run from scratch: `rm results/layer_sel/cells.json`.
